# Автоматический сбор заказов с фриланс-бирж

Это реально, и для начинающего Python-разработчика это хорошая идея: вы получаете инструмент для поиска заказов и готовый проект в портфолио.

## Откуда брать заказы

| Источник | Как получать | Комментарий |
|---|---|---|
| **FL.ru** | RSS-лента проектов, есть фильтр по категориям | Самый простой вариант, парсить HTML не нужно |
| **Habr Freelance** | RSS или парсинг страницы задач | Заказов немного, но они хорошего качества |
| **Kwork (биржа проектов)** | Парсинг HTML или внутреннего JSON | Защита от ботов умеренная |
| **Upwork** | Официальный API (GraphQL, нужно одобрение) | Скрейпинг прямо запрещён правилами, можно получить бан аккаунта |
| **Freelancer.com** | Официальный API | Удобно, есть документация |
| **Telegram-каналы с заказами** | Telethon или Pyrogram (клиентский API) | Часто самый быстрый источник, заказы появляются раньше, чем на биржах |

**Порядок выбора: официальный API, затем RSS, затем парсинг HTML.** Чем выше в этом списке, тем меньше скрипт ломается и тем меньше риск получить блокировку.

## Что можно сделать

Простой бот, который присылает вам в Telegram подходящие заказы:

```
[источники: RSS / API / Telegram]
      → сбор раз в 2–5 минут (APScheduler)
      → фильтр по ключевым словам: python, парсер, бот, django, fastapi, автоматизация
      → минус-слова: дизайн
      → дедупликация (SQLite/PostgreSQL, хранить id заказа)
      → уведомление в Telegram (aiogram)
```

Стек: `httpx`/`aiohttp`, `feedparser` для RSS, `BeautifulSoup`/`selectolax` для HTML, `Telethon` для каналов, `aiogram`, `SQLAlchemy`, Docker.

Пример сбора с RSS:

```python
import feedparser

KEYWORDS = {"python", "парсер", "бот", "django", "fastapi", "скрипт"}
STOP = {"wordpress", "1с", "битрикс"}

def matches(text: str) -> bool:
    t = text.lower()
    return any(k in t for k in KEYWORDS) and not any(s in t for s in STOP)

feed = feedparser.parse("https://www.fl.ru/rss/all.xml?category=5")
for e in feed.entries:
    if matches(e.title + " " + e.get("summary", "")):
        print(e.title, e.link)
```

Адрес RSS проверьте на самом сайте: категории и URL иногда меняются.

## Важные ограничения

- **Читать заказы можно, откликаться автоматически нельзя.** Автоотклики нарушают правила почти всех бирж, за них банят, и заказчики сразу видят шаблонный текст. Откликайтесь сами, но быстро: на бирже первые 10–15 минут дают огромное преимущество.
- **Соблюдайте вежливый режим запросов**: интервал от пары минут, нормальный User-Agent, без обхода капчи и защиты.
- **Читайте правила площадки (ToS).** Upwork и некоторые другие запрещают скрейпинг явно.
- **Для Telegram заведите отдельный аккаунт**, если будете читать каналы через клиентский API.

## Дополнительные бонусы

1. **Проект для портфолио**: асинхронный сбор данных, парсинг, база данных, бот, Docker и деплой. Это ровно то, что ищут в джунах.
2. **Готовый продукт**: такие боты сами по себе популярный заказ на фрилансе («парсер вакансий/заказов с уведомлениями в Telegram»).
3. **Скорость откликов**: вы начинаете видеть заказы раньше конкурентов.
